## 🐛 Устранение типичных проблем

### 1. Приложение недоступно

**Симптомы:**
- Браузер показывает "Сайт недоступен"
- Тайм-аут подключения

**Решение:**
```bash
# Проверка статуса
docker-compose ps

# Перезапуск сервисов
docker-compose restart

# Если не помогает - полная пересборка
docker-compose down
docker-compose up --build -d
```

### 2. Ошибки базы данных

**Симптомы:**
- "Database connection failed"
- Ошибки аутентификации MongoDB

**Решение:**
```bash
# Проверка логов MongoDB
docker-compose logs mongodb

# Перезапуск MongoDB
docker-compose restart mongodb

# Проверка подключения к MongoDB
docker exec -it finance-tracker-mongodb mongo \
  --host localhost --port 27017 \
  -u admin -p admin123 --authenticationDatabase admin
```

### 3. Проблемы с аутентификацией

**Симптомы:**
- "Invalid credentials"
- Зацикливание на странице входа

**Решение:**
```bash
# Сброс пароля администратора
docker exec -it finance-tracker-mongodb mongo \
  finance_tracker --eval "
  db.localusers.updateOne(
    {username: 'admin'}, 
    {\$set: {password: '\$2a\$10\$zQZY5n1g8.2H3.zQZY5n1g8.2H3.zQZY5n1g8.2H3.zQZY5n1g8.2H3'}}
  )"
```

### 4. Недостаток места на диске

**Симптомы:**
- Ошибки записи в логи
- Медленная работа приложения

**Решение:**
```bash
# Очистка логов Docker
docker system prune -f

# Очистка старых образов
docker image prune -a

# Ротация логов приложения
truncate -s 0 logs/*.log
```

### 5. Высокое потребление памяти

**Симптомы:**
- Медленная работа системы
- Ошибки "Out of Memory"

**Решение:**
```bash
# Проверка потребления памяти
docker stats

# Перезапуск с ограничением памяти
docker-compose down
# Отредактируйте docker-compose.yml добавив:
# deploy:
#   resources:
#     limits:
#       memory: 1G
docker-compose up -d
```

## 📋 Скрипты автоматизации

### Скрипт резервного копирования
```bash
#!/bin/bash
# backup.sh
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="./backups"
mkdir -p $BACKUP_DIR

echo "Создание резервной копии..."
docker exec finance-tracker-mongodb mongodump \
  --db finance_tracker --gzip \
  --archive > $BACKUP_DIR/backup_$DATE.gz

echo "Резервная копия создана: backup_$DATE.gz"

# Удаление старых копий (старше 30 дней)
find $BACKUP_DIR -name "backup_*.gz" -mtime +30 -delete
```

### Скрипт восстановления
```bash
#!/bin/bash
# restore.sh
if [ -z "$1" ]; then
    echo "Использование: ./restore.sh backup_file.gz"
    exit 1
fi

echo "Восстановление из $1..."
docker exec -i finance-tracker-mongodb mongorestore \
  --db finance_tracker --gzip --archive < $1

echo "Восстановление завершено"
```

### Скрипт проверки здоровья
```bash
#!/bin/bash
# health-check.sh
echo "Проверка состояния Finance Tracker..."

# Проверка контейнеров
if ! docker-compose ps | grep -q "Up"; then
    echo "❌ Некоторые контейнеры не запущены"
    docker-compose ps
    exit 1
fi

# Проверка веб-интерфейса
if ! curl -s http://localhost:3000/health > /dev/null; then
    echo "❌ Веб-интерфейс недоступен"
    exit 1
fi

# Проверка MongoDB
if ! docker exec finance-tracker-mongodb mongo \
    --quiet --eval "db.adminCommand('ismaster')" > /dev/null; then
    echo "❌ MongoDB недоступна"
    exit 1
fi

echo "✅ Все сервисы работают нормально"
```

## 📞 Контактная информация

При возникновении критических проблем:

1. **Сохраните логи**: `docker-compose logs > debug.log`
2. **Опишите проблему**: Что делали, что ожидали, что получили
3. **Приложите конфигурацию**: `.env` файл (без паролей)
4. **Укажите версию**: `docker --version`, `docker-compose --version`

## 🛡️ Процедуры восстановления после сбоев

### Полная переустановка
```bash
# Остановка и удаление всех контейнеров
docker-compose down -v

# Удаление образов
docker rmi $(docker images -q finance-tracker*)

# Очистка данных (ОСТОРОЖНО!)
rm -rf data/mongodb/*

# Восстановление из резервной копии
./restore.sh backup_latest.gz

# Запуск системы
docker-compose up -d
```

### Восстановление только приложения
```bash
# Остановка только приложения
docker-compose stop finance-tracker

# Пересборка приложения
docker-compose build finance-tracker

# Запуск приложения
docker-compose start finance-tracker
```
